# Audit the architecture

Read the architecture, scope, and confirmed scale targets. Check assumptions, capacity, growth, cost, security, recovery, operational risks, alternatives, and approvals. Mark unsupported claims and unknown targets. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
