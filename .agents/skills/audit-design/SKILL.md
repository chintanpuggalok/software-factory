# Audit the design

Read the design brief and approved scope. Check relevant taste, market-share evidence, competitor flows, user flows, states, accessibility, and user approval. Cite evidence for findings. Report pass, revise, or blocked. State the next action. Do not claim independent review when the author performs the audit.
