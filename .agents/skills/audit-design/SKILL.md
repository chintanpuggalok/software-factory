# Audit the design

Read the design brief and authorized scope. Check relevant taste, market-share evidence, competitor flows, user flows, states, and accessibility. Check user approval only when required. Cite evidence for findings. Report pass, revise, or blocked. State the next action. Do not claim independent review when the author performs the audit.
