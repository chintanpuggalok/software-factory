# Audit the design

Read the design brief and authorized scope. Check relevant taste, market-share evidence, competitor flows, user flows, states, and accessibility. Check user approval only when required. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.

Market-share check: PASS when dated market-share evidence is cited, or when every candidate is labeled unverified and the brief names the missing source. Do not treat search snippets as market-share proof.
