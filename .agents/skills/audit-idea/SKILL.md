# Audit the idea

Read the idea and its inputs. Check the user, problem, assumptions, direction, and user decisions. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
