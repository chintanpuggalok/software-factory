# Audit the plan

Read the plan, approved scope, and architecture. Check dependencies, scale targets, risks, verification, permissions, and cost. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
