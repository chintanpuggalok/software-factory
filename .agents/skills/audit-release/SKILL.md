# Audit the release

Before deployment, read the release summary and evidence. Check test results, risks, rollback, and required approvals. Record approvals that are still pending. A pass means the release is ready for an approval decision, not that deployment is approved. Do not require production health evidence before deployment.

After deployment, audit production health and the release outcome. Mark missing evidence.

For each audit, cite evidence for findings. Report pass, revise, or blocked. State the next action. Do not claim independent review when the author performs the audit.
