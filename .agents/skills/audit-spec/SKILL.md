# Audit the spec

Read the spec, authorized scope, and confirmed product decisions. Check scope, exclusions, priorities, user flows, and acceptance criteria. Check approval only when required. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
