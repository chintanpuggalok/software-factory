# Audit the spec

Read the spec, authorized scope, and confirmed product decisions. Check scope, exclusions, priorities, user flows, and acceptance criteria. Check approval only when required. Cite evidence for findings. Report pass, revise, or blocked. State the next action. Do not claim independent review when the author performs the audit.
