# Audit taste

Read the taste record and its source. Check context, evidence, user confirmation, project scope, and privacy. Separate hypotheses from confirmed preferences. Cite evidence for findings. Report pass, revise, or blocked. State the next action. Do not claim independent review when the author performs the audit.
