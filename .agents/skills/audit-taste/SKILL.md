# Audit taste

Read the taste record and its source. Check context, evidence, user confirmation, project scope, and privacy. Separate hypotheses from confirmed preferences. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
