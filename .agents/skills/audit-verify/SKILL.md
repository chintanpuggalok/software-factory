# Audit verification

Read the spec, scenario results, and test evidence. Check requirement coverage, failures, missing evidence, and limits of test independence. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
