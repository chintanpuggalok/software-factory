# Audit the visual review

Read the design brief and review evidence. Check browser coverage, screen sizes, core flows, accessibility, design fit, and untested states. Cite evidence for findings. Report `PASS: evidence`, `REVISE: findings`, or `BLOCKED: reason`. State the next action. Record the verdict with the stage output. Do not claim independent review when the author performs the audit.
