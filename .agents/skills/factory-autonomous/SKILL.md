# Run the project

1. Record the goal, authorized scope, release target, constraints, and checkable completion criteria.
2. Select a bounded task with `factory-route`. Run the matching stage and audit. Record actions, evidence, and the next task.
3. Fix failures within authorized scope. Re-run the affected checks. Do not weaken the completion criteria.
4. Continue until the criteria pass. On interruption, use `factory-recover`. Stop for missing access, an external blocker, or a decision that needs authorization.
5. Run `factory-learn` after the work. Report the result and unverified risks.

Use existing prepaid access only. Follow higher-priority permissions for spending, delegation, installation, and deployment. This skill is an instruction, not a running scheduler or restart mechanism.
