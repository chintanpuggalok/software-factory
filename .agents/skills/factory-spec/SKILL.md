# Define the product

1. Read the confirmed product direction and relevant project context.
2. Propose user flows, features, exclusions, and acceptance criteria. Mark assumptions.
3. Identify a smallest useful release and unresolved trade-offs.
4. Ask Chintan to decide scope and priorities. Record the decisions and open questions in a project spec.

Do not treat a proposal as approval. At each stage change, hand over the goal, confirmed decisions, artifact paths, open questions, and next action. Load `factory-design`, `factory-architecture`, or `factory-plan` only when that stage starts.
