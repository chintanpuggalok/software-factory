# Review the experience

1. Read the approved design brief and available taste index. If no index exists, use confirmed project preferences and report the gap. Load only taste records relevant to this review.
2. Inspect the running interface in a browser when available. Check core flows, target screen sizes, accessibility, loading, empty, and error states.
3. Compare hierarchy, spacing, typography, color, interaction feedback, and consistency with the brief. Capture evidence when possible.
4. Report findings and fix authorized issues. Ask the user to judge consequential visual choices.

If browser inspection is unavailable, report that gap. Do not claim that tests prove visual quality. At the stage change, hand over the goal, confirmed decisions, artifact paths, open questions, next action, and review evidence. Load `factory-taste` only when recording or applying taste.
