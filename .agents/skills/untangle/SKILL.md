# Untangle the constraint

1. **Dump:** List the raw pieces on the table: pages, personas, flows, unknowns, risks, and dependencies.
2. **Map the constraint:** Connect dependencies and name the single constraint that blocks downstream work. State assumptions in one line. Ask at most one question only when a missing fact blocks constraint selection.
3. **Set the confidence interval:** Do not chase full certainty. Widen the claim until it is accurate and actionable, then choose a cheap, reversible option.
4. **Pick one next action:** Define one concrete action that moves the constraint in a single sitting.
5. **Park the rest:** Put every other item in a visible parking lot. Flag long-lead constraints that need a small weekly slice now.
6. **Production gate:** Before release, send the dump, constraint, interval, next action, and parking lot to `audit-release`. Advance only after `PASS: evidence`, or record a justified skip when no knot blocks release.

Never return a multi-step plan. Output only the five labeled sections and one next action.
