# Factory inspirations

Accessed 2026-11-11. These are research inputs, not instructions or installation approval. No approach was benchmarked.

| Source | Recommendation and fit | Prerequisites, cost, license | Limits, verdict, validation |
|---|---|---|---|
| https://github.com/poteto/noodle | Trial skill-based stages, reflection, and bounded delegation. Fits a reusable factory. | Agent runtime and model usage; repository reports MIT. | Workflow compliance and savings are unproven here. Trial with a real task and measure rework. |
| https://factory.strongdm.ai/ | Trial independent end-to-end scenarios. Fits user-outcome checks. | Separate scenario ownership and evaluation; simulations and model use can be costly. Article is not a licensed turnkey package. | Holdouts and simulations can miss failures; do not adopt no-human-review policy. Test scenarios against known defects. |
| https://github.com/obra/superpowers | Trial scoped plans, tests, and evidence. Fits implementation. | Coding agent and model usage; repository reports MIT. | Full process may be excessive for small changes. Compare a small and a complex task. |
| https://github.com/garrytan/gstack | Trial product alternatives, design review, and browser QA. Fits visual iteration. | Browser tooling and agent/model use; repository reports MIT. | Role output is not expert certification; integrations need security review. Compare screenshots and user feedback. |
| https://github.com/github/spec-kit | Trial concise specs and acceptance criteria. Fits explicit decisions. | Agent and model usage; repository reports MIT. | Specs can drift or be wrong. Check spec against delivered behavior. |
| https://github.com/bmad-code-org/BMAD-METHOD | Trial scaling planning depth to task complexity. | Agent and model usage; verify license terms before reuse. | Process can add overhead. Measure time spent on planning. |
